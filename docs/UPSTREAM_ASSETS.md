# Original launcher artwork

The Mac app uses the same icon as the Windows Definitive SMR Launcher:
`Definitive-SMR-Launcher/icon/icon.ico`, inherited from
`ageekhere/Definitive-SMR-Launcher`. The source contains one 64 × 64 image.
The build converts that artwork to the sizes required by macOS; larger sizes
are scaled from the original, not newly drawn high-resolution artwork.

This inherited artwork retains its upstream provenance and is outside the
MIT license for Craig Franklin's original Apple Silicon code. Including it
does not assert ownership of it or extend that license to it.

## Optional custom difficulty definitions

The experimental custom-difficulty edition includes the inherited
`Definitive-SMR-Launcher/DSMRL_data/RRT_Difficulty.xml` from the same upstream
repository. Its eleven difficulty definitions retain upstream provenance and
are outside the MIT license for the original Mac code. They are copied only
into a separately identified, opt-in map edition; the commercial game bundle
is never patched. Loading and gameplay behavior remain unverified on the Mac.
